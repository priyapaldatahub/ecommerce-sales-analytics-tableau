# E-Commerce Sales Analytics Dashboard

## Project Overview

An interactive e-commerce sales analytics dashboard created using Tableau Public.

The dashboard analyzes sales performance, profit, orders, customer segments, payment modes, product categories, and regional sales.

## Tools Used

- Tableau Public
- Microsoft Excel
- Data Visualization
- Business Analytics

## Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold
- Average Order Value
- Profit Margin
- Monthly Sales Trend
- Sales by Category
- Top 10 Products by Sales
- Regional Sales Performance
- Sales by Customer Segment
- Sales by Payment Mode

## Business Questions

- How are sales changing over time?
- Which category generates the highest sales?
- Which products are the top sellers?
- Which region contributes the most sales?
- Which customer segment generates the most revenue?
- Which payment mode is used most frequently?
